# File Bridge — кандидат для ручной проверки, 2026-10-20

Изменения локальные, без коммита и публикации. Полный регресс с внешней моделью приостановлен; текущие проверки не подтверждают музыкальное качество или дисциплину Qwen.

## Финальное разделение ответственности

| Файл | Что читать в нём |
| --- | --- |
| [AGENT_GUIDE.md](../artifacts/file-bridge-v3-review/AGENT_GUIDE.md) | Проверка папки, пять творческих сценариев, доставка, исправления и остановка |
| [capabilities.json](../artifacts/file-bridge-v3-review/capabilities.json) | Единственный контракт формата: requestSchema, обязательные поля по режимам, ограничения и ответы |
| [instruments.json](../artifacts/file-bridge-v3-review/instruments.json) | Весь каталог, уникальные canonicalId, совместимость ролей и тембров, MIDI и акустические регистры |
| [music-rules.json](../artifacts/file-bridge-v3-review/music-rules.json) | Термины, сетка и строковые названия тональностей |
| [project-state.json](../artifacts/file-bridge-v3-review/project-state.json) | Текущая revision, вся композиция в score формата halo-score и ограничения scoreExport |

Файлы генерирует текущий код HALO. Отдельного score-state.json и альтернативного внутреннего представления для агента нет. JSON Schema описывает канонический синтаксис; живую ревизию, каталог, тип событий, полифонию и границы каждой фразы дополнительно проверяет получатель HALO. Внешние валидаторы не нужны для работы приложения.

## Закрытые замечания

| Замечание | Итог |
| --- | --- |
| «Fix STATE / RECEIPT» | Удалено. Привязка неизменных переменных пути явно отделена от права записи |
| Запись ответов самим агентом | Только HALO пишет контекст и responses/; агент пишет только requests/ |
| Недоступная папка и поиск замены | До сочинения нужен настоящий probe → ready; при отказе/таймауте остановка без альтернативных папок |
| Права Bionic | Проверяется реальный обмен, а не предположение по успешному чтению. HALO не выдаёт разрешения другому приложению |
| Обязательные voices одновременно с phrases | В схеме отдельные исключающие ветви: замена фразы с voices или песни с phrases + sections |
| Два ambient hat | Внешние ID rain-hat и moss-hat; обе записи однозначно сохраняют исходный банк. Неоднозначный hat не принимается |
| bell MIDI 92 против диапазона 26–88 | Ввод: целый MIDI 0–127. acousticRange описывает воспроизведение с переносом октав, а не отклонение входной ноты |
| setup, числовой key, noteEvents, startStep | Убраны из снимка агента. score использует world, строковую key, meter и notes/steps; позиции локальны для каждой фразы |
| Все фразы композиции | Экспортируются все voices, phrases и sections, не только активная фраза |
| Изменение параметров без потери музыки | patch меняет только перечисленные параметры во всех выбранных фразах, атомарно под одним одобрением |
| Ложный «точный» экспорт генератора | Материализованный цикл явно отмечен; непредставимое состояние даёт score:null. Исходный проект остаётся внутри HALO |
| Переполненный guide | 6 982 символа; без копии схемы, каталога и готовых нотных примеров. Все справочники связаны ссылками |
| Такты и шаги | Международные термины и точные формулы; начало следующего такта не равно увеличению плотности первого |
| Проверка перед отправкой | Проверяются режим, поля, ревизия, тембры, тип/позиции событий, полифония, все ссылки фраз и соответствие реального покрытия задаче |
| Ошибки и циклы | Чтение реального error/help/instructionForAgent, максимум два исправления и ограниченное чтение receipt; терминальные статусы завершают ход |
| Новая задача против исправления | Новые probe/music ID для новой просьбы; тот же ID только для исправления незавершённой ошибки |
| «Обновить снимок» | Обновляет состояние и перечитывает файлы; не обещает исправления или применения устаревшего запроса |

При повторной сверке также приведены к canonicalId названия тембров в scoreAudit, а экспорт генеративных партий использует фактический лад тональности, включая major.

## Как получить живые файлы

1. Откройте локальную изменённую версию HALO. Для сервера из рабочей копии: `./scripts/preview.ps1`, затем `http://127.0.0.1:8766/`.
2. Перезагрузите страницу и подключите прежнюю общую папку. Нажмите «Обновить файлы»; оставьте панель File Bridge и страницу видимыми при автоматическом обмене.
3. Проверьте новый заголовок AGENT_GUIDE.md: **HALO — Compose and edit music**. В capabilities.json должны быть requestSchema и четыре режима probe/replace/edit/patch. В project-state.json — score, без project.
4. Заранее предоставьте внешнему агенту чтение подключённой папки и запись только в её requests/. Права браузера и Bionic независимы.

Для предварительного чтения есть [сгенерированный пакет](../artifacts/file-bridge-v3-review/AGENT_GUIDE.md). Его project-state.json — искусственная тестовая композиция, не ваша музыка. Не копируйте этот снимок в живую папку: актуальный снимок должна сформировать сама HALO. Ваша подключённая папка при разработке не изменялась.

## Ручные задания

Отправляйте задания по одному. Между ними одобряйте результат в HALO; перед следующей просьбой дождитесь обновления состояния. Не отправляйте следующую просьбу поверх ещё не решённого pending_approval.

| Шаг | Простая просьба | Что проверить |
| --- | --- | --- |
| 1 | «Вот папка HALO: ПОЛНЫЙ_ПУТЬ. Прочитай AGENT_GUIDE.md и сочини новогодний луп на 8 тактов» | Настоящий ready до музыки, другой ID для партитуры, правильная папка, узнаваемый праздничный мотив на всей задуманной длительности |
| 2 | «Сделай из этой фразы законченную композицию» | Несколько реально различающихся связанных фраз, исходная тема сохранена, вся структура видна в STATE.score |
| 3 | «Переделай всю композицию в 3/4 и ре минор, замедли вдвое» | BPM действительно вдвое меньше, все фразы в 3/4, реальные MIDI переработаны, а не только подписи |
| 4 | «Теперь новая энергичная пиратская композиция со своей оригинальной мелодией и другими инструментами» | Другая тема и подбор тембров, без переноса новогодней мелодии |
| 5 | «Отключи ударные во всей композиции, сохрани все ноты, инструменты и остальные настройки» | mode:patch; меняются только нужные on, вся музыка и структура сохраняются |

Отдельно можно проверить отказ записи: агент должен завершить попытку до сочинения, назвать путь/отказ и не создавать собственный ответ. Художественное качество и звучание оцениваются прослушиванием, не количеством событий.

## Лёгкая проверка

Выполнены 61 целевой тест File Bridge/ограниченных файловых инструментов, 12 проверок JSON Schema стандартным PowerShell Test-Json и один smoke-тест двуязычного руководства. Сверены ссылки, каталог, экспорт и описание режимов; git diff --check без ошибок. Полный Node-регресс и новый live-прогон модели не запускались. Проверки не подтверждают реальные права Bionic, работу нативного выбора папки, мобильные устройства или качество аудио.

Повторить синтаксическую проверку подготовленного пакета без модели и без записи в подключённую папку: `./scripts/check-file-bridge-contract.ps1`.

# PITCH и аудиовходы — регресс 2026-10-15

## Автоматические проверки

`node --test tests/*.test.cjs`: **184 passed, 0 failed, 0 skipped** (весь проект, 17 тестовых файлов). `git diff --check` проходит.

Новое покрытие:

- MIDI исходной ноты, минор/мажор, ступени и паузы, октавы, предел ±24 полутона и отказ от негармоничного ограничения диапазона.
- Один фрагмент без transient slicing, окно 8 с, trim/offset/reverse, гейт внутри шага и фразы. Live/offline PITCH имеют одинаковые timestamps, скорости, offsets и длительности.
- Изменения рисунка и исходной ноты при выключенном Instant Restart ждут границы фразы. Схема project.liveLoop сохраняет новые поля, копирует массивы и исключает hardware device IDs.
- Все три режима получают запись выбранного входа (fake getUserMedia / Web Audio). PITCH take ограничен 8 секундами; окончание записи освобождает вход без мониторинга.
- Точный deviceId, отключённая обработка голоса в constraints, фильтрация только audioinput, запрет подмены отсутствующего инструментального входа микрофоном.
- Явное/idempotent включение мониторинга; смена входа и отключение устройства; освобождение tracks; отказ разрешения, отсутствие API, запрет смены входа во время записи; выбор восстанавливается локально без автоматического доступа к аппаратуре.
- Восстановленные локальные audio IDs не теряются в снимке до завершения асинхронного IndexedDB load; панель блокирует раннее редактирование до hydration.
- Целостная HTML-разметка всех трёх режимов, уникальные ID, общие входы/импорт, переключение RU/EN с полной перерисовкой панели.
- Resampling 48 kHz recording PCM → 44.1 kHz context сохраняет длительность и частоту тестового тона.

## Браузерные проверки

Codex in-app Chromium, **1280×720** и **390×844**. Preview: `scripts/preview.ps1 -Port 18766`, `http://127.0.0.1:18766/`; изолированный origin с прежними специально созданными тестовыми записями, без изменения пользовательской композиции на основном 8766. Loopback-сервер запущен после стандартной execution escalation; старый browser adapter недоступен, использован текущий поддерживаемый API.

- LOOP → SLICE → PITCH: в каждом режиме ровно один селектор аудиоустройства, управление прослушиванием и импорт.
- PITCH воспроизводится с ансамблем, исходная нота A3 и изменённый второй шаг сохраняются. После перехода композиции соседняя фраза сохранила свой LOOP/Pitch −5; возврат после reload восстановил PITCH/A3/собственный рисунок первой фразы.
- Финальная повторная проверка: импорт нового оригинального тона A3/220 Hz (1 с), LOOP → SLICE → PITCH и reload; аудио и исходная нота восстановились, ошибок консоли нет. Тестовый WAV не включён в репозиторий.
- Тип входа «Инструмент» сохраняется после reload; прослушивание остаётся выключенным. Попытка слушать без выбора конкретного устройства завершилась локальным сообщением без подмены микрофоном.
- RU/EN панели и accessible labels проверены при переключении языка. 390×844 использует вертикальную прокрутку панели; настройки источника и звука располагаются ниже исходной ноты.
- Реальный экспорт композиции с PITCH: `notbad-halo-8bars (2).wav`, stereo PCM16, 44100 Hz, 26.6667 с, peak 0.112610, ненулевой PCM. Проверка файла не является прослушиванием.
- Финальный проход обнаружил ReferenceError `winDur` в SLICE waveform с загруженным аудио. Исправлено определение окна, добавлен тест конечной геометрии отрисовки LOOP/SLICE/PITCH на длинной записи. После исправления повторный браузерный проход не воспроизвёл ошибку. Камера и микрофон физически не включались; разрешение аппаратного захвата в браузере не подтверждалось.

## Ограничения проверки и реализации

Настоящие микрофон/USB-аудиоинтерфейс, инструмент, аппаратная задержка, качество мониторинга/щелчки на слух, unplug реального устройства, Safari/iOS/Android и длительная фоновая запись не проверены. Захват проверен автоматическими fake API; аппаратная приёмка остаётся отдельной. Запись моно через существующий ScriptProcessor; actual constraints зависят от браузера и драйвера. Прямой мониторинг не попадает в экспорт, пока не записан как take.

Автоматического определения исходной ноты, независимого time-stretch/formant processing, захвата системного выхода, ASIO, MIDI и выбора каналов интерфейса нет. Для устройства нужны HTTPS/localhost и разрешение браузера; имена/доступность входов до разрешения ограничены: [MDN enumerateDevices](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/enumerateDevices).

Новых внешних звуков, зависимостей, CDN или сервера нет. Новый classic script подключён относительным путём; версия URL обновлена у затронутых скриптов. Приложение сохраняет статическое размещение GitHub Pages под /<repository>/; реальный deploy не выполнялся. Коммитов нет.
